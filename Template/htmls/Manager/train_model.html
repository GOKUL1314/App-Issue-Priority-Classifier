ML Pipeline Architecture
  • Text Feature: TfidfVectorizer (1-2 ngrams, sublinear_tf)
  • Categorical Features: OneHotEncoder (app_area, link_status, device)
  • Numeric Features: MinMaxScaler (contacts, hours, past_issues)
  • Production Storage: joblib (priority_model.joblib)
Platform Rules (Can Only RAISE)
  • Rule A - Live Product Link Broken:

    When app area is "Product Link", link status is "Live", contacts shared >= 1, and text indicates link not opening / 404 / error, priority is raised to High.

  • Rule B - Account Security & Data Loss:

    When text describes cannot log in, account locked, hacked, someone else in account, or products/data lost, priority is raised to High.

  • Strict Guardrail Invariant:

    Rules may only RAISE a priority, never lower it. Cosmetic downgrade rules have been completely removed.
